# TurboLoad — Smart Download Manager

واجهة تنزيل عربية ثابتة تعمل داخل المتصفح.

## طريقة التسريع

- تفحص الرابط باستخدام HEAD وتجربة نطاق بايت واحد.
- عندما يدعم الخادم Range وتسمح سياسة CORS بالقراءة من المتصفح، تنزّل الملف في أجزاء متوازية.
- تتحقق من استجابة كل جزء وحجمه، وتعيد المحاولة حتى مرتين.
- تستخدم حفظًا مباشرًا إلى ملف حين يوفر المتصفح File System Access API؛ وإلا تحد حجم التنزيل المقسّم لتقليل خطر استهلاك الذاكرة.
- إذا لم تنجح هذه الشروط، تعرض التنزيل المباشر بدل الادعاء أن التسريع نجح.

## ملاحظات مهمة

هذه صفحة static فقط، ولا يوجد فيها وسيط تنزيل خلفي. لذلك لا تستطيع قراءة الملفات من كل المواقع: يلزم السماح بطلبات المتصفح عبر CORS. ولا يمكن لأي مدير تنزيل تجاوز حد السرعة الإجمالي الذي يفرضه الخادم أو مزود الاتصال. الاتصالات المتعددة تساعد فقط عندما يكون الاتصال الواحد هو عنق الزجاجة ويقبل الخادم الطلبات الجزئية.

لا تضع روابط خاصة أو روابط تحتوي بيانات دخول. استخدم روابط تنزيل تملك الإذن في الوصول إليها.
